# Shopee 平台图片合规规则

## 一、主图（Cover Image）规范

### 1.1 背景要求
- 主图建议使用**纯白色或浅色背景**。
- 各站点要求略有不同：
  - 台湾站：强烈建议纯白背景
  - 新加坡/马来西亚站：白底或浅灰底
  - 印尼/泰国/越南站：白底优先，浅色也可接受
  - 菲律宾站：白色或浅色纯色背景
- 背景必须干净整洁，无杂乱物品或干扰元素。

### 1.2 无牛皮癣原则
Shopee 对主图有严格的"无牛皮癣"要求，**禁止**出现：
- **促销信息**："SALE"、"Discount"、"限时特价"、"清仓甩卖"、"Buy 1 Get 1"
- **价格信息**：任何定价、折扣、优惠标签
- **水印/Logo**：店铺Logo、品牌水印、网址、社交媒体账号
- **广告语**："Best Seller"、"爆款"、"Hot Sale"
- **边框/装饰**：装饰性边框、花纹框
- **表情包和卡通贴图**：任何非商品元素的装饰图案
- **二维码/条码**：扫描类图像
- **拼图/分割线**：多图拼接效果

### 1.3 商品展示
- 商品必须**清晰完整**地展示，居中放置。
- 商品占比建议 **≥ 70%**，能清楚看到商品全貌。
- 必须展示**实际销售的商品**，不得使用效果图、渲染图代替实拍照。
- 套装/组合商品需在一张图中展示所有包含的物品。
- 变体商品：每个变体SKU需要对应颜色的商品实拍照。

### 1.4 尺寸与分辨率
- 图片最短边分辨率必须 **≥ 800 像素**。
- 推荐尺寸：**1024x1024 像素** 或 **1600x1600 像素**。
- 比例建议为 **1:1**（正方形），支持的最大比例为 **1:1.5**。
- 单张图片文件大小不超过 **2MB**（部分站点放宽至5MB）。
- 分辨率 **72 DPI** 即可，不需要过高分辨率。

### 1.5 文件格式
- 支持格式：**JPEG**（推荐）、**PNG**。
- JPEG 压缩质量建议 **85-95%**，兼顾清晰度和加载速度。
- PNG 适用于无背景商品图（仅限辅图）。
- 不支持动图 GIF、BMP。

## 二、辅图规范

### 2.1 图片数量要求
- 每个商品至少 **3张** 图片。
- 建议上传 **6-9张** 图片以提高转化率。
- 最多可上传 **9张** 图片（Shopee标准限制）。

### 2.2 辅图内容建议
以下图片类型建议按顺序排列：
1. **第1张**：白底主图或干净的商品实拍图
2. **第2-3张**：不同角度展示（侧面、背面、45度角）
3. **第4-5张**：细节特写（材质、做工、纹理）
4. **第6张**：尺寸图（服装/鞋类必选）
5. **第7张**：使用场景图/Lifestyle图
6. **第8张**：颜色变体对比（如有多种颜色）
7. **第9张**：包装/配件展示

### 2.3 辅图规范细节
- 辅图可以包含**场景、模特、装饰元素**。
- 辅图**允许**添加文字说明、尺寸标注、功能注解。
- 辅图允许非白色背景。
- 所有辅图保持**风格一致**，提升品牌专业感。

## 三、尺码图规范（服装/鞋类必选）

### 3.1 服装尺码图
- **强烈建议**所有服装类商品上传尺码图。
- 尺码图需包含以下信息：
  - 各部位测量示意图
  - 尺码对应具体数值（厘米）
  - 建议身高体重范围（可选，但推荐）
  - 测量方法说明（如"自然平铺测量"）
- 常见标注部位：
  - 上装：肩宽、胸围、袖长、衣长
  - 下装：腰围、臀围、裤长、大腿围
  - 连衣裙：肩宽、胸围、腰围、裙长

### 3.2 鞋类尺码图
- 必须提供**国际尺码对照表**。
- 包含：US、UK、EU、JP、CN 尺码对比。
- 建议提供脚长与码数对应表。
- 标注鞋垫长度和宽度（厘米）。

### 3.3 尺码图视觉要求
- 文字清晰可读，建议中号字体以上。
- 尺寸数据准确无误，与实际商品一致。
- 建议使用**图文结合**方式，左边示意图 + 右边数据表。

## 四、详情页（Description）图片规范

### 4.1 图片尺寸
- 详情图宽度建议：**640-800 像素**。
- 高度不限，但单张比例建议不超过 3:1。
- 所有详情图宽度统一，保证浏览体验。
- 单张图片不超过 **1MB**（确保移动端加载速度）。

### 4.2 详情页必须包含的内容
- 商品规格参数表
- 使用说明/注意事项
- 材质/成分说明
- 售后服务政策（退货/保修条款）
- 包装清单

### 4.3 详情页内容限制
- **禁止**出现其他电商平台链接或引导文字。
- **禁止**出现其他平台的Logo或名称（如淘宝、Lazada、Amazon等）。
- **禁止**引导买家通过站外方式交易（留微信、LINE、WhatsApp等）。
- **禁止**使用极限词和虚假宣传。
- **禁止**盗用其他卖家原创图片。

### 4.4 详情页排版建议
- 采用**长条图**（纵向滚动）设计，适配手机端浏览。
- 信息密度适中，适当留白。
- 使用店铺统一配色和字体。
- 重点信息用**加粗**、**色块**等方式突出。

## 五、商品视频规范

### 5.1 视频要求
- 视频时长：**10-60 秒**。
- 视频比例：**1:1** 或 **9:16**（竖版）。
- 分辨率 ≥ **720P**。
- 视频大小不超过 **200MB**。
- 封面图必须从视频中截取，清晰无模糊。

### 5.2 视频内容
- 建议展示：商品360度旋转、使用场景、模特穿着效果。
- 前3秒需抓住买家注意力。
- 视频中允许添加**字幕说明**和**品牌Logo**。

## 六、各站点特别要求

### 6.1 台湾站
- 主图中的文字说明**必须使用繁体中文**。
- 尺码图建议同时标注台尺和厘米。
- NCC（台湾通讯传播委员会）认证商品需展示认证标签。

### 6.2 印尼站
- 清真（Halal）认证商品需展示认证标志。
- BPOM（印尼食品药物监管局）注册商品需展示注册号。
- 主图文字建议使用**印尼语**或英语。

### 6.3 泰国站
- 建议使用**泰语**文字说明。
- 泰国有严格的海关限制商品（如化妆品），需提供合规证明。

### 6.4 巴西站
- 文字说明建议使用**葡萄牙语**。
- ANATEL认证（通讯产品）和ANVISA认证（健康产品）信息需在图片中展示。
- 巴西站对进口商品有较高关税，建议标注含税信息。

### 6.5 墨西哥站
- 文字说明使用**西班牙语**。
- NOM认证标识需在电子产品图片中展示。

## 七、违规处理

### 7.1 扣分机制
| 违规行为 | 扣分 |
|---------|------|
| 使用非自己拍摄的图片 | 2分 |
| 图片包含外部链接/联系方式 | 2分 |
| 图片包含误导性信息 | 2分 |
| 图片违反Shopee禁售政策 | 2-12分 |
| 图片侵犯知识产权 | 2-15分 |
| 图片包含不当内容 | 最高15分 |

### 7.2 处罚措施
- 累计扣分 **≥3分**：限制参加促销活动28天
- 累计扣分 **≥6分**：限制参加促销活动 + 商品搜索排名下降
- 累计扣分 **≥12分**：店铺冻结7天
- 累计扣分 **≥15分**：店铺永久冻结

### 7.3 优化建议
- 定期使用Shopee卖家中心检测主图合规性。
- 关注Shopee官方规则更新，平台政策可能随时调整。
- 使用专业摄影 + 适度后期处理，避免过度修图。
- 主图不合规是新手卖家最常见的违规原因之一，务必重视。
