# 淘宝/天猫平台图片合规规则

## 一、主图规范

### 1.1 尺寸与比例
- 主图标准尺寸为 **800x800 像素**，比例必须为 **1:1**（正方形）。
- 支持更大的正方形尺寸，如 1000x1000、1200x1200 像素。
- 最小尺寸不低于 **700x700 像素**。
- 非 1:1 比例的主图会导致商品在某些频道无法正常展示。

### 1.2 无牛皮癣原则
主图必须保持干净，**禁止**出现以下"牛皮癣"元素：
- **促销文字**：如"5折"、"限时特价"、"包邮"、"第二件半价"
- **Logo/水印**：品牌Logo、店铺Logo、任何水印标识
- **价格信息**：原价、折扣价、划线价等
- **排名信息**：No.1、爆款、热卖、榜单排名
- **边框**：任何颜色或样式的装饰性边框
- **拼接图**：多图拼接、分格展示
- **二维码**：任何扫码入口

### 1.3 商品展示
- 主图必须是**实拍商品图**，建议纯色背景。
- 商品清晰完整，无遮挡，居中展示。
- 商品主体占比建议 ≥ 70%。
- 套装/组合装商品应展示完整商品组合。
- 主图不能是**效果图、渲染图、手绘图**（原创设计类除外，需提供原创证明）。

## 二、白底图要求

### 2.1 为什么要白底图
- 淘宝/天猫的**猜你喜欢**、**有好货**、**淘宝头条**等公域频道会自动抓取白底图。
- 白底图质量直接影响商品在推荐频道的**曝光率**和**点击率**。
- 没有合格白底图的商品**无法进入**这些高流量公域频道。

### 2.2 白底图规范
- 第5张主图位置建议放置白底图（部分类目强制要求）。
- 背景必须为**纯白色** RGB(255, 255, 255)。
- 商品必须**抠图处理**，去掉原有背景。
- 商品边缘清晰平滑，无白边残留或过度羽化。
- 商品角度：
  - 服装类：正面平铺或正面直立
  - 鞋类：侧面45度展示
  - 包袋：正面展示
  - 化妆品：正立展示

### 2.3 白底图尺寸
- 标准尺寸：**800x800 像素**。
- 天猫部分类目要求白底图规格为 **1000x1000 像素**。
- 商品占图片面积 **75%-85%** 为佳。

### 2.4 不适合白底图的情况
- 生鲜水果类（鲜活场景更受欢迎）
- 大型家具类（白底难以展现全貌）
- 定制服务类（如设计服务、咨询服务）
- 虚拟商品（如充值卡、游戏道具）

## 三、长图/竖图规范（手淘首页）

### 3.1 适用场景
- **手淘首页**竖图坑位（如"每日好店"、"有好货"）。
- **有好货**频道的商品卡片使用竖版图片。
- **微详情**中的商品展示。

### 3.2 尺寸要求
- 竖版图片比例：**2:3** 或 **3:4**。
- 推荐尺寸：**800x1200 像素** 或 **900x1200 像素**。
- 宽度 ≥ 600 像素，高度 ≥ 900 像素。

### 3.3 内容要求
- 竖图应为**场景图**或**模特图**，而非白底图。
- 展示商品的实际使用场景。
- 图片顶部 1/3 区域应是吸引眼球的视觉焦点。
- 文字信息（如有）应放在图片下半部分。

### 3.4 长图（详情页顶部）
- 详情页顶部支持上传长图，宽度 **750-790 像素**。
- 高度不限，但建议不超过 1500 像素。
- 用于展示商品整体效果和核心卖点。

## 四、详情页规范

### 4.1 图片尺寸
- PC端详情页图片宽度建议：**750 像素**（天猫）、**790 像素**（淘宝）。
- 移动端详情页（手淘）宽度建议：**750 像素**（自适应宽度 640 像素）。
- 单张图片宽度需统一，避免宽窄不一影响阅读体验。

### 4.2 图片内容
- 详情页必须包含：
  - 商品全貌展示图（至少1张）
  - 细节特写图（至少2张）
  - 尺寸规格图
  - 材质/工艺说明图（如适用）
- 信息展示顺序建议：
  1. 场景图/海报图（吸引停留）
  2. 核心卖点图（功能特性）
  3. 规格参数图（尺寸数据）
  4. 细节实拍图（品质展示）
  5. 对比图（如有）
  6. 包装/售后信息

### 4.3 禁止内容
- **极限词**：全网第一、极品、顶级、绝对、100%
- **虚假宣传**：夸大功效、虚构数据
- **误导信息**：PS过度的对比图
- **侵权内容**：盗用他人原创图片
- **竞品对比**：直接贬低竞争品牌
- **外链引导**：引导到其他电商平台

### 4.4 详情页规范通用要求
- 图片清晰度高，文字可辨识。
- 整体设计风格统一。
- 重点信息需突出标注（用加粗、高亮等方式）。
- 模特图拍摄风格与品牌定位一致。

## 五、视频内容规范

### 5.1 主图视频
- 时长：**9-60 秒**（建议30秒以内）。
- 比例：**1:1**（正方形）或 **16:9**（横版）。
- 分辨率：≥ **720P**，推荐 1080P。
- 视频大小：不超过 **200MB**。
- 封面图必须高清且无牛皮癣。

### 5.2 视频内容建议
- 前3秒展示商品全貌。
- 中间展示使用场景和功能。
- 结尾展示品牌信息或引导购买。

## 六、品类特殊规定

### 6.1 服装类
- 必须提供**尺码表**图片（至少包含胸围、衣长、肩宽、袖长）。
- 模特必须穿着实物，不得用效果图代替。
- 多色SKU需展示各颜色实拍（可用拼图展示，但仅限详情页）。

### 6.2 化妆品类
- 主图需展示产品实物（含包装）。
- 详情页可展示使用效果对比（需标注"效果因人而异"）。
- 不得使用过度磨皮/美颜后的效果图误导消费者。

### 6.3 食品类
- 主图需展示食品实物（不是包装盒）。
- 详情页必须包含**生产许可证号**、**保质期**等信息的图片。
- 国产食品需展示中文标签。

### 6.4 3C数码类
- 主图建议展示正面 + 45度角。
- 详情页需包含接口图、配件清单图。
- 有屏幕的产品建议展示亮屏效果图。

## 七、常见违规与处罚

| 违规类型 | 处罚措施 |
|---------|---------|
| 主图牛皮癣 | 搜索降权 |
| 图片盗用 | 投诉即下架、扣分 |
| 虚假宣传 | 下架+扣分+罚款 |
| 白底图缺失 | 无法进入公域频道 |
| 尺码图缺失 | 影响转化率（平台提醒） |
| 极限词违规 | 下架+扣分（2-12分） |

- 一般违规每次扣 **2-4 分**。
- 严重违规每次扣 **12-48 分**。
- 年度累计扣分达 **48 分**将面临封店处理。
